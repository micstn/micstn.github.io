This is the first essay in the new markdown-based publishing workflow. It exists to confirm that a markdown file can render cleanly into a standalone page with the site’s editorial styling.

The goal is to keep the experience quiet, direct, and legible. Each essay should feel like a small publication object rather than a bloated landing page.

The structure stays simple: a title, a brief description, the written body, and a path back to the archive. That rhythm is what makes the site feel editorial instead of promotional.
